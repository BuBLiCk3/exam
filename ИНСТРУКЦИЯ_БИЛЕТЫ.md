# Инструкция по созданию и оформлению экзаменационных билетов по конспектам

Данная инструкция фиксирует правила, структуру и алгоритм работы при добавлении новых фото конспектов и оформлении недостающих билетов.

---

## 1. Главные правила и ограничения

1. **Строго по конспектам (Zero Hallucination):**
   * Запрещено додумывать факты, классификации, примеры или даты, которых нет в рукописях.
   * Если в конспекте приведены конкретные цифры, авторы, примеры стран или списки — переносить именно их.
   * Сокращения конспекта («опр.», «соц.-эконом.», «об-во», «ООПТ», «гос-во») расшифровывать в литературную грамотную форму без изменения смысла.

2. **Объединение двух источников (Настя + Савелий):**
   * Всегда сверять обе тетради по каждой теме.
   * Включать детали, которые есть у одного автора, но пропущены у другого (например: примеры профессий, расшифровка задач, схемы стрелок, термины).
   * Выбирать наиболее полные и аккуратные формулировки определений.

3. **Работа с недостающими темами:**
   * Не создавать пустых файлов-заглушек под билеты, если по ним нет записей в конспектах.
   * В итоговом отчёте всегда явно перечислять номера и темы билетов, по которым пока нет фото/материалов.

---

## 2. Алгоритм действий при получении новых фото

1. **Определение предмета и автора:**
   * Положить фото в соответствующую папку (`География/Настя`, `География/Савелий`, `Общество/Настя`, `Общество/Савелий`).
2. **Ориентация и порядок страниц:**
   * Обратить внимание на ориентацию страниц (при необходимости учитывать поворот).
   * Определить хронологический порядок страниц (часто нумерация фото в Telegram/мессенджерах идёт в обратном порядке от последней страницы к первой).
3. **Сопоставление с вопросами из `.docx`:**
   * Открыть `.docx` файл со списком вопросов к аттестации/экзамену.
   * Найти заголовки в конспектах (обычно темы в конспекте выделены маркером или цифрами в квадратах) и сопоставить с номерами билетов.
4. **Синтез билета:**
   * Выписать все определения, классификации, списки, схемы и таблицы.
   * Оформить отдельный файл билета в папке `билеты/`.
5. **Обновление общего файла:**
   * Пересобрать общий сводный файл (`Все_билеты_География.md` или `Все_билеты_Обществознание.md`), объединив все актуальные билеты по порядку номеров.

---

## 3. Шаблон оформления файла билета

Каждый отдельный билет оформляется строго по следующему шаблону в файле с именем `Билет_XX_Краткое_название.md`:

```markdown
# Билет №X. [Тема билета из docx списка]

## Вопрос билета
[Точный текст формулировки вопроса из официального документа .docx]

---

## Конспект ответа

### 1. [Название ключевого раздела / Понятие]
* **Определение:** [Текст определения из конспекта]
* **История / автор термина:** [Если есть в конспекте]

### 2. [Классификация / Структура]
[Если в конспекте таблица — оформлять markdown-таблицей; если стрелочная схема — оформлять ASCII/текстовой схемой или маркированным списком]

| Категория / Вид | Суть / Определение | Примеры из конспекта |
| :--- | :--- | :--- |
| **Вид 1** | Описание | Пример 1, Пример 2 |
| **Вид 2** | Описание | Пример 3 |

### 3. [Задачи / Практика / Особенности]
[Формулы оформлять в KaTeX: $R = \frac{\text{Запасы}}{\text{Добыча}}$]
* Подробные шаги решения и выводы строго по рукописям.
```

## 4. Памятка по структуре папок проекта

```
exam/
├── География/
│   ├── Вопросы к ПА 10 класс (2).docx
│   ├── Настя/                  # Фото конспекта
│   ├── Савелий/                # Фото конспекта
│   ├── билеты/                 # Отдельные файлы билетов (Билет_01.md ... Билет_20.md)
│   └── Все_билеты_География.md # Сводный файл всех готовых билетов
│
├── Общество/
│   ├── Экзаменационные_вопросы_по_обществу.docx
│   ├── Настя/                  # Фото конспекта
│   ├── Савелий/                # Фото конспекта
│   ├── билеты/                 # Отдельные файлы билетов (Билет_01.md ... Билет_20.md)
│   └── Все_билеты_Обществознание.md # Сводный файл всех готовых билетов
│
├── ИНСТРУКЦИЯ_БИЛЕТЫ.md        # Настоящая инструкция
└── README.md
```
