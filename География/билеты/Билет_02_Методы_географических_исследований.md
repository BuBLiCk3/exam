# Билет 2. Методы географических исследований

## Вопрос билета
Что такое методы географических исследований. Классификация методов. Что такое аэрокосмический, геоинформационный методы. Использование методов.

---

## Конспект ответа

### 1. Определение
* **Методы географических исследований** — способы изучения объектов, явлений и процессов.

### 2. Классификация методов

| Традиционные методы | Новые (современные) методы |
| :--- | :--- |
| 1. Описание | 1. Аэрокосмические |
| 2. Наблюдение | 2. Космические |
| 3. Сравнение | 3. Геоинформационные (ГИС) |
| 4. Исторические | 4. Моделирование |
| 5. Картографические | 5. Большие данные (Big Data) |
| 6. Статистические | 6. Мониторинг |

### 3. Характеристика отдельных методов
* **Геоинформационный метод (ГИС):** 
  * Географическая информационная система — взаимосвязь всех этапов получения, хранения, переработки и отбора данных и выдачи географической информации в виде электронных карт.
  * Выступает одновременно как метод исследования и как источник информации.
* **Аэрокосмический метод:**
  * Дистанционное зондирование Земли (ДЗЗ), использование спутниковых снимков, мониторинг с помощью БПЛА (беспилотных летательных аппаратов).
  * Применяется для составления актуальных карт, прогнозирования погоды, мониторинга природных явлений и антропогенных изменений.
