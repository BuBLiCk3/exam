# Билет 3. Географическая культура

## Вопрос билета
Что такое географическая культура, кто и когда раскрыл понятие. Элементы географической культуры: географическая картина мира (определение, из чего складывается картина мира), географическое мышление (определение), язык географии (определение), методы географии (определение, классификация методов). Значимость географической культуры для представителей разных профессий.

---

## Конспект ответа

### 1. Понятие географической культуры
* **Определение:** Географическая культура — часть общей культуры человека: знания, умения и ценности, которые позволяют понимать устройство пространства Земли и своё место в нём.
* **Кто и когда раскрыл понятие:** Понятие раскрыл **Владимир Павлович Максаковский** в книге «Географическая культура» (1998 г.).

### 2. Элементы географической культуры
1. **Географическая картина мира:**
   * *Определение:* Целостный образ планеты: как устроены её природа, население и хозяйство — и как они связаны между собой.
   * *Из чего складывается:*
     * Природа Земли (климат, ресурсы);
     * Население (численность, расселение);
     * Мировое хозяйство (отрасли);
     * Общество и природа (воздействие и развитие).
2. **Географическое мышление:**
   * *Определение:* Умение видеть явления привязанными к месту и объяснять, почему они возникли именно здесь.
   * *Складывается из характеристик:* территориальность, комплексность, глобальность.
3. **Язык географии:**
   * *Определение:* Система, на которой география говорит о пространстве (карты и условные знаки, понятия и термины, географические названия, цифры, схемы, географические образы).
4. **Методы географии:**
   * *Определение:* Способы изучения объектов, явлений и процессов (традиционные: описание, наблюдение, картографический и др.; новые: аэрокосмический, ГИС, моделирование и др. — см. тему методов).

### 3. Значимость географической культуры для представителей разных профессий

| Элемент геогр. культуры | Профессия | Значимость / Применение |
| :--- | :--- | :--- |
| **Географическая картина мира** | Дипломат, международник | Понимание международной ситуации и глобальных связей |
| | Журналист-международник | Объяснение мировых событий в контексте стран |
| | Экономист (специалист ВЭД) | Оценка внешних рынков и логистических цепочек регионов |
| | Офицер, аналитик МЧС | Учет пространственной обстановки на территориях |
| **Географическое мышление** | Урбанист, градостроитель | Выбор оптимального места для районов, дорог, парков, промзон |
| | Логист | Построение маршрутов, учет шлюзов, границ, стоимости перевозок |
| | Агроном | Подбор сортов под климат, почву и рельеф местности |
| | Эколог | Оценка антропогенного воздействия на конкретную среду |
| **Язык географии** | ГИС-специалист, картограф | Работа со слоями карт, пространственными координатами, электронными картами |
| | Геолог, гидролог, метеоролог | Точные отчеты и прогнозы на основе условных обозначений и измерений |
| | Гид, менеджер по туризму | Обзор территорий для туристов, навигация по маршрутам |
| | Кадастровый инженер, геодезист | Использование географических координат, межевание, топографические планы |
| **Методы географии** | Картограф, геоинформатик | Проведение съемок, создание карт |
| | Географ-политолог | Анализ пространственного распределения сил |
| | Специалист по ДЗЗ, оператор БПЛА | Аэрокосмический мониторинг территорий |
| | Демограф, социогеограф | Анализ данных переписей и миграций |
| | Геомаркетолог | Сравнение локаций и территорий для открытия бизнеса |
| | Этнограф | Полевые исследования расселения и быта народов |

### Вопросы, которые задаёт географ при анализе размещения производства (из конспекта):
1. Какова доля сырья в готовой продукции и насколько оно транспортабельно?
2. Где находятся главные потребители?
3. Какова экологическая ситуация?
4. Насколько развита транспортная инфраструктура?
5. Что перевесит и чем придётся пожертвовать:
   * *Месторождение сырья:* перевесит минимальные затраты на перевозку сырья, пожертвует удаленностью от рынков сбыта.
   * *У морского порта:* перевесит удобный экспорт за рубеж, пожертвует высокой стоимостью доставки сырья от мест добычи.
   * *Рядом с крупным городом:* перевесит близость к кадрам, научным центрам и местному рынку, пожертвует жесткой экологией и сильным загрязнением.
